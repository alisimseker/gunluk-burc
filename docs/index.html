Günlük Burç

Bu sayfa uygulamanın içerik sunucusudur. Günlük yorumlar v1/<burç>.json dosyalarındadır.

Gizlilik

Uygulama hesap açtırmaz, kişisel veri toplamaz ve kimseyle paylaşmaz. Seçtiğiniz burç yalnızca kendi telefonunuzda saklanır. Uygulama günlük yorumları bu adresten indirir; bu sırada yalnızca standart internet bağlantı bilgileri (IP adresi) GitHub sunucularına ulaşır.
